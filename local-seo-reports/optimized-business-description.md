## Choices and their reasons
- **No prices, offers, URLs or phone numbers.** GBP's description policy rejects promotional offers and links. Prices belong in the Services section.
- **No "best", "#1" or "highest-rated".** The site's "Guelph's highest-rated lawn care" claim can't be backed with current data, so it stays off the GBP.
- **Guelph is mentioned once and Puslinch/Aberfoyle once.** Repeating place names doesn't help rankings and reads as spam.
- **Crew size and lawn count are left out** until the owner confirms the real figures (the site says both 35+ and 50).
- **Review count is left out.** It changes constantly and is unverified.
- **Expectation:** Google says it uses the description for understanding, but there's no good evidence that description keywords move Maps rankings. This edit improves clarity and conversion. It is not a ranking lever.
